# Iftekhar Lab website

This is a responsive academic lab website starter with a restrained, traditional university-research layout inspired by the structure of academic lab websites such as Moraru Lab. It is not a copy of their text or branding.

## Site files
- `index.html` — page structure and content
- `styles.css` — layout, typography, responsive styling
- `script.js` — mobile navigation and current year
- `assets/` — reserved for local photos and other media

## Preview locally
Open `index.html` in a modern browser.

## Publish for free using GitHub Pages
1. Create a GitHub account and a repository named `iftekhar-lab-website`.
2. Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, and save.
5. Use the URL GitHub Pages provides.

## Team editing
The site is static and does not yet include a login-based content management system. Trusted team members can edit files through GitHub's web interface or submit pull requests. A CMS can be added later with separately configured authentication. Do not place passwords or private API keys in the repository.
